# Laporan LaTeX UTS INF301

Dokumen utama: [main.tex](main.tex).
Hasil PDF: [laporan-uts-pcd-kelompok-9.pdf](../pdf/laporan-uts-pcd-kelompok-9.pdf).

Sampul mencantumkan Bambang Herlambang (5803024019) dan Dustin Pranata
Wangsawidjaja (5803024021). Laporan mencakup soal nomor 1 dan 3.

Struktur sumber:

- `main.tex`: pengaturan halaman, sampul, dan daftar isi.
- `sections/`: pendahuluan, pembahasan soal, pengujian, dan penutup.
- `images/`: salinan gambar hasil program yang digunakan pada laporan.

Sampul mengikuti referensi tata letak yang diberikan pengguna. Logo UKWMS
diambil dari [situs resmi Fakultas Teknik](https://ft.ukwms.ac.id/)
([berkas PNG](https://static.wixstatic.com/media/c22b9c_a429e65614504b0da9446714c820e6c7~mv2.png)).

Seluruh sumber dan gambar berada dalam folder ini, sehingga folder dapat
dibuka sebagai satu proyek LaTeX atau diunggah utuh ke editor LaTeX.
Pilih `main.tex` sebagai dokumen utama. Kompilasi minimal dua kali jika
menggunakan pdfLaTeX agar daftar isi, nomor gambar, dan sitasi diperbarui.

Data hasil pada laporan merupakan hasil eksekusi dengan parameter default.
Jika kode atau gambar masukan diubah, jalankan ulang program dan perbarui
salinan gambar serta angka dalam sumber sebelum mengompilasi kembali.
